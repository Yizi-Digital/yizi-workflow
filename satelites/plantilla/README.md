## Empezar

1. Clona el núcleo y regístralo como store: `openspec store register <ruta-del-núcleo> --id yizi-workflow`.
2. Abre Claude Code en este repo y acepta el plugin `yizi-nucleo`.
3. Comprueba la conexión: `openspec doctor`.
4. Propón el primer cambio: `/openspec-propose <idea>`.

Las reglas del núcleo prevalecen. Ver `AGENTS.md`.
